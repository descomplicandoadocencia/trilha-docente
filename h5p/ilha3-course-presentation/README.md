# H5P · Ilha 3 · Course Presentation + Drag and Drop

**Bibliotecas:** H5P.CoursePresentation 1.23 + H5P.DragQuestion 1.14 + H5P.Text 1.1
**Localização:** `/h5p/ilha3-course-presentation/`

## Conteúdo programático

10 slides:

1. Definição de Metodologia Ativa (Moran)
2. Por que mudar a sala de aula (TALIS / PISA)
3. Sala de Aula Invertida
4. Rotação por Estações
5. Laboratório Rotacional
6. Flex Model
7. Quadro comparativo
8. **Drag and Drop** — Montar estação ideal (5 categorias, 7 opções, 2 distratores)
9. Erros frequentes
10. Recursos abertos

## Como gerar o `.h5p` definitivo

1. No [Lumi](https://lumi.education), escolha **Course Presentation** e importe `content.json`;
2. Revise o slide 8 — o componente `H5P.DragQuestion 1.14` deve aparecer;
3. Exporte o `.h5p` e extraia aqui. O Lumi inclui as bibliotecas (`H5P.CoursePresentation-1.23/`, `H5P.DragQuestion-1.14/`, etc.).
