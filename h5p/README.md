# Pacotes H5P

Extraia aqui os pacotes `.h5p` exportados do Lumi, um por pasta:

- `ilha1-interactive-video/` — Interactive Video (autoavaliação de fluência digital)
- `ilha2-branching-scenario/` — Cenário ramificado PBL (crise ambiental escolar)
- `ilha3-course-presentation/` — Course Presentation + Drag and Drop (rotação por estações)
- `ilha4-dialog-cards/` — Dialog Cards (prompts de IAG × análise crítica)
- `ilha4-documentation-tool/` — Documentation Tool (plano de aula + Declaração de Uso Ético)

Cada pasta deve conter `h5p.json`, `content/content.json` e as bibliotecas embutidas.
